# YouTube metadata

## Title

AIﾉアカリ☆ MV Atelier — Native WebMCP Human-Agent Collaboration

## Description

One human doodle becomes a visible time-coded MV graph that a human and an agent edit together through native WebMCP.

Live app: https://ai-akari-webmcp-mv-atelier.vercel.app/?lang=en
Public code: https://github.com/AInoAKARI/ai-akari-webmcp-mv-atelier
Native acceptance evidence: https://github.com/AInoAKARI/ai-akari-webmcp-mv-atelier/tree/master/evidence

The demo uses browser-local pixel analysis, ten structured tools discovered through document.modelContext.getTools(), native executeTool(set_mood), visible shared-state mutation and persistence after reload. No paid model or video provider is required.
